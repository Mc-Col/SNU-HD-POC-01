## 발표에서 먼저 말할 것

1. **근거없음오답 0건** — 문서에 근거가 없는 곳에서 값을 만들지 않았다.
   정확도보다 이 숫자가 먼저다. 이 과제가 없애려는 문제가 그것이기 때문이다.
2. **68% → 86% → 92%** 를 무엇으로 올렸는지 — 별칭·프롬프트이고 모델을 바꾼
   것이 아니다(`docs/eval_history.md` 에 before/after 가 남아 있다).
3. **100% 정확도는 증명할 수 없다** — rule of three. 표본 11건이면 상한이 넓다.
   측정의 한계를 먼저 말하지 않으면 숫자 전체가 의심받는다.
4. **페이지를 사람이 알려주고 있다** — 위 B. 숨기면 안 된다.

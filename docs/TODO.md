## 발표에서 먼저 말할 것

1. **근거없음오답 0건** — 문서에 근거가 없는 곳에서 값을 만들지 않았다.
   정확도보다 이 숫자가 먼저다. 이 과제가 없애려는 문제가 그것이기 때문이다.
2. **68% → 86% → 92% → 93%** 를 무엇으로 올렸는지 — 별칭·프롬프트이고
   **모델을 바꾼 것이 아니다**(`docs/eval_history.md` 에 before/after 가 있다).
   그리고 92%→93% 의 1칸은 **잡음**이라고 먼저 말한다 — 상위 모델이
   손대지 않은 칸에서 왔다(인사이트 53).
3. **상위 모델은 비용을 정당화하지 못했다** — 그리고 그 결론에 이르기까지
   내 크롭 결함이 -5칸을 만들었다. 도구를 의심하지 않으면 "상위 모델이
   나쁘다" 는 틀린 권고를 했을 것이다(인사이트 51).
4. **100% 정확도는 증명할 수 없다** — rule of three. 표본 11건이면 상한이 넓다.
   측정의 한계를 먼저 말하지 않으면 숫자 전체가 의심받는다.
5. **비용 사다리의 무료 칸을 아직 안 만들었다** — 규칙 검증(무료)을 건너뛰고
   상위 모델(유료)부터 붙였고, 측정해 보니 유료 칸이 값을 못 했다. 가장 많이
   틀리는 `valve_body_material` 은 어휘 대조로 공짜로 잡힌다(위 I).
6. **페이지를 사람이 알려주고 있다** — 위 B. 숨기면 안 된다.

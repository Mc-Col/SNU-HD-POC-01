### 작성 원칙

현재 업무와 의사결정을 먼저 적고, AI·LLM·강화학습 같은 방법론은 뒤에 비교한다.

확인된 사실과 가정을 구분하고, 미확인 사항은 추가 확인 질문으로 남긴다.

모델 성능뿐 아니라 실제 사용자, 업무 반영 지점, 운영 KPI를 함께 정의한다.

AI가 최선의 방법이 아닌 것으로 분석되면 데이터 정비, 규칙 표준화, 최적화, 시뮬레이션 등을 선택한다.

### A-2. 현재 문제 상황

| 확인 질문 | 작성 |
|---|---|
| 현재 누가 어떤 방식으로 업무를 수행하는가? | 설비 엔지니어 30명이 벤더 데이터시트를 육안 판독하여 마스터DB에 직접 입력함. 벤더별 표기·단위가 표준화되어 있지 않아 정규화 판단을 사람이 매 건 수행함.<br>· 문서 — 스캔 이미지 30% / 텍스트 PDF 30% / 엑셀 40%, 벤더 5개사 이상(벤더당 양식 최대 3종)<br>· 소요 — 건당 이미지 2h / 텍스트 PDF 1.5h(가정) / 엑셀 1h → 가중평균 1.45h<br>· 물량 — 인당 월 20건 이상(신규+변경) → 부서 전체 월 600건<br>· 승인 — 입력자 본인 1차 → 도면관리 담당자 최종 (2단) |
| 반복되는 불편·지연·위험·재작업은 무엇인가? | ① 판독·정규화의 전면 수기 의존 — 벤더별 표기가 상이함. | 이 문제로 발생하는 손실 또는 리스크는 무엇인가? | [유입분] 건당 172,500원(일괄 반영 100,000원 + 인건비 1.45h × 50,000원) × 월 600건 = 월 1.04억원 / 연 12.42억원 / 상시 5.2 FTE(30명 중 17%). 이 중 40%가 오류이며 활용률이 0%이므로 실질적으로 연 12.42억원 전액이 회수되지 않음<br>[전량] 미정비 30만 태그 = 435,000시간 = 216 FTE-년 = 517.5억원. 현행 처리 속도(연 7,200건) 기준 41.7년, 30명 전원 전담 시 7.2년. 개선 과제가 아니라 착수 가능성의 문제임<br>[리스크] Fail Action 등 안전 사양 오류는 비상 시 밸브 거동 판단 오류로 이어질 수 있음. 예지보전·디지털트윈이 정확한 기준정보를 전제하므로 후속 AI 과제 착수가 불가함<br>※ 오류율 40%는 현업 체감치이며 실측 이력 없음. PoC 중 골든셋 100건 대조로 실측 확정 |
| 왜 지금 이 문제를 다루어야 하는가? | ① 처음으로 이 데이터의 소비자가 생김 — 디지털트윈 사전작업 착수. 지금까지 활용되지 않아 품질 요구도 거버넌스도 발생하지 않았으며, 악순환 루프가 끊어지는 최초 시점임<br>② 개선 대상이 아니라 착수 조건임 — 전량 정비에 41.7년(517.5억원). 인력 증원으로 해결되는 규모가 아님<br>③ 기술 장애물 해소 — 2021년 최대 장벽이었던 스캔 문서 판독이 Vision AI 성능 향상으로 실무 적용 수준에 도달함<br>④ 손실 진행 중 — 스마트 계장 진단 데이터는 늘고 있으나 기준정보에 해당 항목이 없어 활용하지 못함 |

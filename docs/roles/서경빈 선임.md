## 담당하는 파일 — `schema/` 셋

| 파일 | 성격 | 고치는 방법 |
|---|---|---|
| `fields.yaml` | 필드 정의·유사표현·임계 | **손으로 고치지 않습니다.** `python tools/gen_schema.py` 로 재생성 (원본 `readme/output_sample.xlsx`) |
| `rules.yaml` | 단위·표기 변환 사전 | 손으로 고칩니다. 주석이 많으니 기계로 덮어쓰지 마세요 |
| `guidance.yaml` | **자연어 판단 지침** | 손으로도, 화면에서도 고칩니다 (이종수 책임 공동) |

`fields.yaml` 에 유사표현을 넣으려면 `tools/gen_schema.py` 의 딕셔너리를
고쳐야 합니다. 그 파일이 필드 표준의 원본입니다.

### `guidance.yaml` 이 왜 따로 있나

`rules.yaml` 은 기계가 적용하는 결정론적 규칙입니다. `guidance.yaml` 은
**그것으로 적을 수 없는 판단 기준을 사람 말로 적는 곳**입니다. 확인필요·N/A 가
뜨면 화면이 이 글을 그대로 보여줍니다 — 검토자가 매번 같은 판단을 다시
발명하지 않게 하는 것이 목적입니다.

화면(HITL 의 `[지침]` 버튼)에서도 편집되기 때문에 `rules.yaml` 과 분리했습니다.
기계가 덮어쓰면 `rules.yaml` 의 주석이 사라집니다.

현재 9개 필드에 지침이 있습니다. 실물을 보다가 "이건 사람이 판단해야 하는데" 싶은
게 나오면 여기 적어 주세요.

## 담당 모듈

### `src/parsers/text`

**③-a TEXT PARSER — 헤더를 표준 컬럼에 붙인다**

- 입력: `엑셀 시트 또는 텍스트 PDF 페이지`
- 출력: `RawExtraction[]`

할 일:

1. 셀·텍스트 블록을 스캔해 라벨 후보 추출
2. 헤더 텍스트 → 표준 컬럼명 매핑 (`fields.yaml` 의 `name` + `aliases`)
3. 라벨 우측·하단 셀에서 값 추출 → `source_locator` 에 `Sheet1!C7` 형태로 기록
4. **`raw_label` 에 문서에 적힌 항목명을 그대로 담기** ← 유사표현 사전의 원료
5. 매핑 실패 라벨은 `unmapped` 로 수집해 로그에 남기기

**꼭 알아야 할 실측 결과 — 텍스트만으로는 표를 못 읽습니다**

텍스트 레이어가 온전한 PDF 에서 텍스트를 뽑아보면 라벨과 값의 연결이 무너져
있습니다. 실제 예:

```
... OPEN CLOSE ...          ← 값만 한 덩어리로
... Silver Green Green ...  ← 라벨과 멀찍이 떨어져
... Flow to  Signal increase to  Fail Position ...   ← 라벨은 딴 곳에
```

글자는 100% 있는데 어느 값이 어느 필드인지 알 수 없습니다. 그래서 설계가
이렇습니다 — **VLM 이 어느 텍스트가 어느 필드인지 정하고, 텍스트 레이어가 그
글자를 보증합니다.** Text Parser 는 **엑셀처럼 셀 주소가 정확한 경우**에 가장
강합니다. PDF 는 VLM 과 함께 씁니다.

하지 말 것:

- **셀 좌표로 매핑하지 말 것** — 벤더 양식의 디테일이 바뀝니다. 헤더 텍스트 기준으로
- `aliases` 를 코드에 넣지 말 것. `fields.yaml`(생성원 `tools/gen_schema.py`)에만

### `src/validate/format`

**⑤-a 형식·허용값 검증**

- 입력: `정규화된 값`
- 출력: `판정 + 위반 사유`

할 일:

1. 필수 필드 충족 검사 (`fields.yaml` 의 `required`)
2. 타입·형식 검사 (숫자여야 하는 필드에 문자가 왔는지 등)
3. 위반 시 `FailureKind.FORMAT` 으로 표시하고 사유를 남기기

하지 말 것:

- 위반을 발견하면 재시도를 요청하지 말 것 — 형식 위반은 사람에게 넘깁니다
- 범주형 허용값 리스트는 MVP 범위 외
- **단위 표기 변형을 위반으로 잡지 말 것** — 옛 데이터시트는 단위를 사람이 손으로
  썼고 `H`·`Hr`·`hr` 이 전부 Hour 입니다. 숫자만 맞으면 통과입니다

## 실측 — 포맷 분포

대상 1,021건 중:

| 포맷 | 건수 | 비율 |
|---|---|---|
| `tif` (스캔) | 734 | **71.9%** |
| `pdf` | 169 | 16.6% |
| `xlsx`·`xlsm` | 118 | **11.6%** |

이전 문서에 "엑셀 우선 (전체의 40%)" 이라고 적혀 있었는데 실측은 11.6% 입니다.
**엑셀은 작습니다.** 다만 셀 주소가 정확해서 Text Parser 가 가장 확실하게 동작하는
경로이고, 유사표현 사전을 여기서 가장 싸게 수집할 수 있습니다.

**Text Parser 의 몫이 늘었습니다.** 정비·개조 보고서 112건이 범위에 들어왔고
(2026-08-24 결정) 그중 **111건이 텍스트 레이어를 갖고 있습니다.** 사양 블록이
텍스트로 있는 것도 많습니다 — 예: `10PV018-REPAIR REPORT` 시트 3 의
`CONTROL VALVE SPECIFICATIONS` (2,568자). 다만 **표 구조가 무너진 텍스트**라
라벨↔값 연결은 VLM 이 정합니다(아래 참조).

데이터시트 PDF 108건 중 전 페이지 텍스트는 45.4% 뿐이고 **51.9% 가 텍스트·스캔
혼재**입니다. `preprocess.probe_pages()` 가 페이지 단위로 판정해 줍니다.

## 골든셋 라벨링 — 10건

`raw_file/서경빈 선임님/` 폴더입니다. `readme/labeling_kit.xlsx` 에 채워 주세요.

```
070100_REV0.pdf                  ← 어려움 (아래 참조)
11FV039-REPAIR REPORT_REV0.pdf   ← 아래 참조
11FV044-DATA SHEET_REV0.tif      11FV502-DATA SHEET_REV0.pdf
11FV048-DATA SHEET_REV2.xlsx     11LV001-DATA SHEET_REV0.tif
11FV049-DATA SHEET_REV0.tif      11LV008-DATA SHEET_REV0.tif
11FV052-DATA SHEET_REV0.tif      44LV001-DATA SHEET_REV1.xlsx
```

**`11FV039-REPAIR REPORT` 도 대상입니다** (2026-08-24 결정). 정비·개조 보고서는
범위 안입니다 — 안에 사양 페이지가 있으면 그 페이지에서 값을 읽습니다.

다만 이 건은 내용이 `DAMPER ACTUATOR REPAIR` 로 **컨트롤밸브가 아닙니다.**
그래서 컨트롤밸브 필드가 거의 채워지지 않을 것입니다. 읽히는 것만 적고
나머지는 `N/A` + 비고로 두세요. 비고에 "댐퍼 액추에이터 정비 — 컨트롤밸브
아님" 을 적어 주시면 그 자체가 좋은 측정 케이스가 됩니다.

`out_of_scope` 로 적는 것은 도면·계기 목록처럼 설비 사양표가 아예 없는
문서입니다.

**`070100_REV0.pdf`** 는 어려운 케이스입니다. 2007년 Honeywell **견적서**이고
7페이지 전부 텍스트인데, 안에 **서로 다른 밸브 2대**의 사양표가 각각 들어 있습니다.

| 페이지 | 내용 |
|---|---|
| p1~p3 | 견적서 표지 · 단가표 · 요약표 |
| **p4** | Control Valve Specification — `B10-TV-040` |
| **p5** | Control Valve Specification — `B10-TV-1016` |
| p6~p7 | Detail Information (각 태그별) |

파일명이 견적번호(`FMKY-070100`)여서 **어느 밸브가 이 파일의 주인인지 알 수
없습니다.** 기대 동작은 "자산 2건 발견 → 사람이 선택" 입니다. 라벨은 p4 나 p5
하나를 골라 채우시고, 비고에 "견적서, 자산 2건(B10-TV-040 / B10-TV-1016) 중
하나를 임의 선택" 이라고 적어 주세요.

참고 — 이 파일의 태그는 `B10-TV-040` 처럼 **앞에 문자가 붙습니다.** 명명 규칙은
`Area - 설비종류 - 일련번호` 이고 Area 는 문자+숫자(`B10`)입니다. 문자가 없으면
A 가 생략된 것입니다(1공장). **적을 값은 문서에 적힌 그대로** — 없는 A 를 만들어
넣지 마세요.

소요 시간은 기록하지 않아도 됩니다.

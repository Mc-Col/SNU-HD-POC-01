## 남은 담당 모듈

### `src/normalize`

**④ NORMALIZE — 표준값으로 바꾼다**

- 입력: `RawExtraction[]`
- 출력: `표준값 + transform_trace`

할 일:

1. 도메인 규칙 적용 — `schema/rules.yaml` 을 읽어서. 코드에 규칙을 넣지 않는다
2. 변환 과정을 `transform_trace` 에 단계별로 기록
3. **ATO/ATC 역전** — `Air-to-Open` → FAIL **CLOSE** / `Air Fails Valve to Open` →
   FAIL **OPEN**. 판별자는 `Fails` 의 유무다. 거의 같은 문장이 반대 결과를 낸다

하지 말 것:

- 단위 변환은 MVP 범위 외 — 원문 표기 그대로 보존 (To-be)
- 범주형 허용값 정규화도 범위 외
- **태그에 없는 `A` 를 만들어 넣지 말 것** — 정규화 키(`A10FV011`)와 내보내는
  값(`10FV011`)은 다르다. `TagParts.raw` 를 쓴다

### `src/validate/domain`

**⑤-b 도메인·물리 제약 검증**

- 입력: `정규화된 값 세트`
- 출력: `판정 + 위반 사유`

할 일:

1. **표기 일관성 검사** — 원문이 직접 기재(`Fails` 포함)인데 결과가 반대면,
   또는 역전 표기인데 결과가 같으면 역전 규칙 오적용이다.
   `pipeline.DefaultDomainValidate` 에 참조 구현이 있다 (6개 사례 검증됨)
2. 유효 ANSI 클래스 / 표준 배관 규격 검사
3. 위반 시 `FailureKind.CONSTRAINT` — 재시도하지 않고 사람에게

하지 말 것:

- **`FAIL ACTION ↔ ACTUATOR TYPE` 교차검증은 MVP 에서 돌지 않는다** —
  C027 에서 `ACTUATOR TYPE` 을 추출 대상에서 뺐기 때문이다. `rules.yaml` 의
  `cross_check` 는 비어 있고 사유가 적혀 있다. FAIL ACTION 의 안전장치는
  **사람 확인 하나**다
- Cv 물리 교차검증은 루프에서 제외 — 화면의 `[Cv 계산]` 버튼 기능으로 별도
- 제약 위반에 재시도를 걸지 말 것 (환각 제조)

### `src/state`

**⑥ STATE — 셋 중 하나로 확정한다**

- 입력: `검증 결과`
- 출력: `FieldRecord`

할 일:

1. `fields.yaml` 의 `threshold`·`safety` 로 상태 결정 (AUTO / REVIEW / NA)
2. `note` 를 생성한다 — AUTO 외 상태는 `note` 가 비면 계약 위반으로 예외
3. 안전·식별 필드는 AUTO 여도 사람 확인 필요 표시 (임계 0.95, 1.00 아님)
4. `FieldRecord.validate()` 를 반드시 호출

하지 말 것:

- 임계값을 코드에 하드코딩하지 말 것 — `fields.yaml` 에서 읽는다
- 평가 Agent 미구현 상태에서 통과시키지 말 것 — `NullVerifyAgent` 는 `False` 를
  돌려준다(fail-safe). 미구현 검증기가 조용히 승인하면 안 된다

### `src/ui` — 이미 만들어져 있음, 남은 것만

- `source.py` 의 `page_path` 가 PDF 만 채워진다 → **TIF(80.7%)가 `None`** 이다.
  `preprocess.render_pages()` 로 교체하면 해결된다. **가장 급하다**
- `pick_latest_spec()` 이 `None` 을 돌려줄 때의 화면 — "자산 N건 발견" ·
  "최신 판정 불가, 사람이 선택" 을 사유 문구와 함께 보여주기
- 제외된 파일(`scope_reason()`)의 표시 — 왜 처리하지 않았는지

## eval — 아직 비어 있음

`eval/harness.py`

- **홀드아웃 잠금** — 골든셋 30건 중 일부는 개발 중 보지 않는다
- **`--no-vlm`** — API 없이도 텍스트 경로만으로 측정
- **3-way A/B** — 텍스트 단독 / VLM 단독 / VLM+텍스트
- **숫자만 대조** — 단위 표기 변형은 감점하지 않는다.
  옛 데이터시트는 단위를 사람이 손으로 썼고 `H`·`Hr`·`hr` 이 전부 Hour 다
- **제외가 정답인 케이스 포함** — 정비보고서를 데이터시트로 착각하지 않는지
- **rule of three** — 100건 오류 0건이면 95% 상한이 약 3%.
  **100% 정확도는 증명할 수 없다.** 발표에서 이 점을 먼저 말한다

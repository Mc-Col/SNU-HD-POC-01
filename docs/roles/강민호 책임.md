## 먼저 알아야 할 것 — 이미 만들어져 있는 도구

`src/preprocess.py` 에 전처리 도구가 다 들어 있습니다. **다시 만들지 마세요.**
담당 모듈은 이 도구를 **조립해서 판정하는 일**입니다.

| 함수 | 하는 일 |
|---|---|
| `parse_filename(path)` | 태그·문서종류·rev → `FileNameInfo` |
| `scope_reason(path)` | 제외 사유 문구 (없으면 빈 문자열) |
| `probe_pages(path)` | 페이지별 텍스트 레이어 유무·글자수 |
| `render_pages(path, out_dir, dpi, pages)` | tif/pdf/xlsx → 페이지별 PNG. 필요한 장만 렌더 가능 |
| `make_montage(pngs, out)` | 썸네일 격자 — VLM 1회로 여러 페이지 판정 |
| `parse_doc_date(text)` · `find_marks(text)` | 날짜 · RETROFIT/OLD 표기 |
| `pick_latest_spec(pages, file_tag)` | 사양표 후보 중 하나 선택 + 사유. 못 가리면 `None` |
| `find_tags(text)` · `normalize_tag(s)` | 태그 추출(나열 펼침) · 정규화 키 |

확인:

```
python -m src.preprocess                      도구 자체 확인
python fixtures/preprocess/test_tag.py        태그 규칙 51건
python fixtures/preprocess/test_recency.py    페이지 선택 30건
```

**변경이 필요하면 이종수 책임에게 요청하세요.** 공용 파일입니다.

## 실측 — 우선순위가 여기서 나옵니다

대상 1,021건의 포맷:

| 포맷 | 건수 | 비율 | 경로 |
|---|---|---|---|
| **`tif`** | **734** | **71.9%** | 전부 스캔 → **VLM** |
| `pdf` | 169 | 16.6% | 데이터시트 108 + 보고서 61 |
| `xlsx`·`xlsm` | 118 | 11.6% | 시트=페이지. 이미지 시트는 VLM |

**VLM 이 주 경로입니다.** 이전 문서에 "스캔 이미지가 30%" 라고 적혀 있었는데
실측은 71.9% 입니다. PDF 텍스트 파싱은 생각보다 작은 몫입니다.

대상 중 **정비·개조 보고서가 112건(11.0%)** 이고 그중 **111건이 텍스트 레이어를
갖고 있습니다.** 이건 범위 안입니다(2026-08-24 결정) — 사양 칸이 비어 있으면
`N/A` + 사유로 두면 되고, 그 판단 자체가 측정 대상입니다.
`preprocess.caution_reason()` 이 경고 문구를 돌려줍니다.

PDF 는 **파일의 51.9% 가 텍스트·스캔 혼재**입니다. 텍스트 레이어 판정을 파일
단위로 하면 절반이 틀립니다 — `probe_pages()` 가 페이지 단위로 돌려줍니다.
임계는 100자이고, 20~500자 사이에서 판정이 거의 변하지 않으므로 튜닝 불필요합니다.

## 담당 모듈

### `src/triage`

**① TRIAGE — 이 파일에 데이터가 있나, 어느 페이지를 볼 것인가**

- 입력: `파일 경로`
- 출력: `TriageResult`

할 일:

1. `parse_filename()` → 태그·문서종류. **문서종류 97.3% 가 여기서 무료로 해결됩니다**
2. `scope_reason()` 이 비어 있지 않으면 `out_of_scope` + 그 문구를 `reason` 에
3. `probe_pages()` → `PageInfo.has_text_layer` · `text_len` 채우기
4. `render_pages()` → `PageInfo.render_path` 채우기 (**화면이 이걸 씁니다**)
5. `make_montage()` → VLM 이진 판정 1회로 `page_class` 채우기
6. 사양표 후보가 2장 이상이면 후보만 원본 해상도로 렌더 → 날짜·표기·태그 읽기 →
   `pick_latest_spec()` 호출
7. `pick_latest_spec()` 이 `None` 이면 **고르지 말고** 확인필요로 넘기기

**페이지 선택 규칙 — 최신성입니다**

한 파일에 사양표가 여러 장이면 **가장 최신인 한 장**만 봅니다.

```
① 폐기 표기(OLD·SUPERSEDED·VOID·폐기) 있는 후보 제외 — 사람이 이미 표시함
② 같은 설비의 다른 시점인가, 다른 설비인가 — 태그 교집합으로 가른다
③ 같은 설비면 연도 최신 → 월·일 → RETROFIT/AS-BUILT/REVISED 표기
④ 다른 설비면 파일명 태그로 선택. 파일명에 태그가 없으면 "자산 N건 발견"
⑤ 못 가리면 고르지 않는다 → 확인필요
```

이 규칙은 실물에서 나왔습니다. `10FV011-DATA SHEET_REV1.tif` 는 사양표가 2장인데
p1 이 4개 태그를 담은 2003년 Retrofit 사양서, p4 가 단독 태그의 1986년 원본
(수기 "OLD")입니다. **단독성으로 고르면 `MODEL NO.`(657-ED vs 667-ED)와
`RATED CV`(70.7 vs 95)가 틀립니다.**

반대 케이스도 있습니다. `070100_REV0.pdf` 는 견적서 한 건에 서로 다른 밸브
2대(`B10-TV-040`, `B10-TV-1016`)의 사양표가 각각 들어 있습니다. 이건 최신성
문제가 아니라 **자산 N건** 문제입니다. 판별자는 태그 교집합입니다.

하지 말 것:

- 예외를 던지지 말 것 — 미지원 포맷은 UNSUPPORTED 로 기록하고 정상 반환
- **태그 단독성으로 페이지를 고르지 말 것** (위 실물 참조)
- 못 가릴 때 아무거나 고르지 말 것 — `None` + 사유가 정답입니다
- `out_of_scope` 판정 시 `reason` 을 비우지 말 것. 조용히 건너뛰면 처리 실패와
  구분되지 않습니다
- MVP 는 1파일 = 1자산 전제. 여러 건이면 "자산 N건 발견" 만 띄우고 하나만 검출

### `src/router`

**② ROUTER — 어느 파서로 보낼지**

- 입력: `TriageResult + 파일`
- 출력: `ParserType + 처리 단위 목록`

할 일:

1. 엑셀 계열 → 포맷별 리더 분기 (`xlsx`/`xlsm` 는 openpyxl, `xls` 는 xlrd)
2. **페이지 단위로** 분기 — `PageInfo.has_text_layer` 를 보고 결정
3. tif → 전부 VLM
4. 판정 근거를 남긴다

하지 말 것:

- **파일 단위로 텍스트/스캔을 판정하지 말 것** — PDF 파일의 51.9% 가 혼재입니다
- 확장자만 보고 분기하지 말 것
- 임계값을 하드코딩하지 말 것 (`preprocess.TEXT_LAYER_MIN`)

### `src/parsers/vlm`

**③-b VLM PARSER — 이미지에서 값과 위치를**

- 입력: `페이지 이미지 + 필드 정의`
- 출력: `RawExtraction[]`

할 일:

1. `schema/fields.yaml` 의 `name`·`desc`·`aliases` 를 프롬프트에 주입
2. 값 + `bbox` + `confidence` 를 함께 요구 (**bbox 가 화면 하이라이트의 근거**)
   `bbox` 규약: 정규화 0.0~1.0, 좌상단 원점, 페이지별 독립
3. 문서에 없으면 `raw_value=None` 으로 정직하게 반환
4. 재시도 요청 시 bbox 크롭만 재판독
5. `raw_label` 에 문서에 적힌 항목명을 그대로 담기 — 유사표현 사전이 여기서 자랍니다

**VLM 과 텍스트 레이어의 역할 분담**

**VLM 이 어느 텍스트가 어느 필드인지 정하고, 텍스트 레이어가 그 글자를 보증합니다.**
텍스트 레이어를 "VLM 을 건너뛰는 지름길" 로 쓰지 마세요. 실측: 텍스트 레이어가
온전한 PDF 에서도 뽑아보면 `OPEN`/`CLOSE` 가 한 덩어리로, 색상값이 라벨과 멀찍이
떨어져 나옵니다. 글자는 100% 있는데 어느 값이 어느 필드인지 알 수 없습니다.

비용 절감은 **페이지 수를 줄이는 데서** 얻고, 판독 단계를 생략해서 얻지 않습니다.

하지 말 것:

- 재시도 프롬프트에 '값이 틀렸다' 고 쓰지 말 것 — 환각을 유도합니다
  올바른 문구: *'이 영역에 문자 그대로 무엇이 적혀 있는지 보고하라.
  같은 값이면 같다고 답하라'*
- 제약 위반에 재시도를 걸지 말 것. 재시도는 추출 실패(못 읽음)에만
- 없는 값을 추정해서 만들지 말 것

## 알아둘 함정 (실물 확인분)

| 함정 | 내용 |
|---|---|
| **하단 회사명 ≠ 제조사** | 10FV011 하단 `VALSTONE SERVICE, CO.` 는 시공사. 제조사(Fisher)는 Note 의 한국어 문장에 있습니다. 반대로 Metso 데이터시트는 하단이 실제 제조사 — 문서 성격(RETROFIT/REPAIR)으로 갈립니다 |
| **ATO/ATC 역전** | `Air-to-Open` → FAIL **CLOSE**(역전) / `Air Fails Valve to Open` → FAIL **OPEN**(직접). 판별자는 `Fails` 의 유무 |
| **파일명 문서종류가 거짓일 수 있음** | `B19V10-DATA SHEET_REV1.xlsx` 의 내용은 2010년 TA Retrofit 체크시트입니다 |
| **엑셀은 시트 = 페이지** | 통째로 PDF 로 내보내면 5시트가 인쇄면 13장이 되어 번호가 어긋납니다. `render_pages()` 가 시트당 1장으로 처리합니다 |
| **격자에서 태그 글자는 안 읽힘** | 480px 썸네일로 종류 판정은 되지만 태그는 못 읽습니다. 태그 대조는 원본 해상도에서 따로 |

## 우선순위

1. **`src/triage`** — 파일명 판정 + 페이지 렌더 + 격자 판정. `render_path` 를
   채우는 것이 급합니다. 화면이 TIF(80.7%)를 표시할 수 없는 상태입니다
2. **`src/parsers/vlm`** — 주 경로입니다. `bbox` 를 반드시 함께 반환
3. `src/router` — 페이지 단위 분기. 도구가 이미 있어 조립만 하면 됩니다

## 참고

- 지원 포맷: `xlsx` `xlsm` `xls` `pdf` `tif`. `doc`/`docx`/`dwg` 는 범위 외
- `xls` 는 `openpyxl` 로 못 읽습니다 → `xlrd` 분기 (`probe_pages()` 는 이미 처리)
- Windows 의 `glob` 은 대소문자를 구분하지 않습니다. `*.pdf` + `*.PDF` 로 세면
  두 배가 됩니다 — `os.path.normcase` 로 중복 제거하세요
- 렌더는 **PNG**, JPG 아닙니다. 손글씨 스캔에서 JPG 잡티가 판독을 방해합니다

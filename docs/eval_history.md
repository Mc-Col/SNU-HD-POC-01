# 평가 실행 이력

`eval/harness.py` 가 실행마다 한 줄을 덧붙인다. 지우지 않는다 — 이 표가
없으면 "무엇을 바꿨더니 올랐나" 를 말할 수 없다.

**읽는 법** — `근거없음오답` 을 먼저 본다. 문서에 근거가 없는 곳에서 값을
만든 건수다. 정확도가 올라도 이것이 늘면 개선이 아니다. 이 과제가 없애려는
문제를 재생산한 것이기 때문이다.

리포트 전문은 `runs/eval/<시각>-<stage>.md` 에 있다(Git 제외).

# 원격 병합 인수인계

**상태** 로컬 커밋 3개는 푸시하지 않았다. `origin/main` 에 조원 커밋 10여 개
(77파일 · 7,417줄)가 있고 **겹치는 파일이 3개**다. 자동 병합을 걸지 않는다.

    git log --oneline origin/main..HEAD    내 것 3개
    git log --oneline HEAD..origin/main    조원 것

## 2. 내 판단이 틀렸던 것 — Deskew

**골든셋으로는 deskew 효과를 측정할 수 없었다.**

    골든셋 14건        0.5° 초과  1건 ( 7%)   ← 이걸로 "제외" 판정했다
    코퍼스 tif 40건    0.5° 초과 20건 (50%)   중앙값 0.62° · 최대 1.75°
    조원 실측 758건    0.5° 초과       71.5%

내 구현이 틀린 게 아니다 — 두 측정이 거의 일치한다(d001 −1.25° vs −1.50°).
**표본이 달랐다.** 골든셋 14건 중 실제 스캔은 5건뿐이고 나머지는 xlsx·텍스트PDF 라
구조적으로 0.00° 다. 자세한 것은 인사이트 58.

## 3. 조원에게 알려야 할 것 — 확대 임계가 우리 코퍼스를 비껴간다

    TARGET_LONG_EDGE_PX   = 2576
    UPSCALE_TRIGGER_RATIO = 0.5      → 장변 ≤ 1288 일 때만 확대
    MAX_UPSCALE_FACTOR    = 2.0

    우리 tif 장변 1753  →  1288 < 1753 < 2576  →  배율 1.0 (손대지 않음)

**2배 확대는 이 세션 최대 개선이었다 — 엄격 77% → 83% · 오답 45 → 29.**
그 설계에서는 안 걸리고, 걸려도 상한이 2576/1753 = 1.47배다.

`constants.py` 주석의 *"없는 화질을 만들지 못한다"* 는 **계조 얘기로는 맞고 획 크기
얘기로는 틀리다.** 고쳐진 값이 전부 한두 획 차이였다 —
`120→138` · `2.4→7.4` · `21.2→21.6` · `.94→0.74`. 1↔3, 2↔6, 9↔5, 2↔7.

**제안** 임계를 장변 기준 절대값(예 ≤ 2000)으로 바꾸거나, 상한을 3000~3500 으로
올린다. **바꾸기 전에 우리 리플레이로 재채점해 확인할 수 있다 — API 비용 0원.**

    python -m eval.harness --replay runs/raw/terra_x2

## 4. 손으로 병합할 파일 3개

| 파일 | 내 변경 | 원격 변경 | 방법 |
|---|---|---|---|
| `src/parsers/vlm/openai_vlm.py` | 프롬프트 15규칙 · `D2S_UPSCALE` · `D2S_PROMPT` · 포지셔너 차단 | `absence_reason` · `row_text` · `cache` · `deskew` · 응답 스키마 | **둘 다 살린다.** 원격을 바탕으로 내 프롬프트 규칙을 얹는다. 규칙과 스키마가 서로 독립이라 실제 충돌은 응답 JSON 예시 한 곳뿐 |
| `src/pipeline.py` | `DefaultNormalize` 의 FAIL 어간 판정 + 모호성 가드 | `build()` 팩토리 | 겹치는 함수가 없다 — 양쪽을 이어 붙인다 |
| `schema/rules.yaml` | `enum_allowed_values` 활성 · 표준값 아라비아 숫자화 · 별칭 확장 | 스키마 생성 관련 | 키가 달라 대부분 나란히 놓인다. **`valve_leakage_class`·`characteristic` 표준값은 내 쪽이 최신**(CLASS 4 · EQUAL PERCENTAGE) |

**병합 후 반드시** — `python -m eval.harness --replay runs/raw/terra_x2` 로
관대 89 · 값만 87 · 엄격 83 · 지어냄 4 가 재현되는지 확인한다. 안 나오면 병합이
무언가를 끊은 것이다.

## 5. 설계 어긋남 — 실은 어긋나지 않았다

원격 `src/triage/` 가 페이지를 자동 분류한다. 우리는 *"사람이 화면에서 고른다"* 로
결정했다. **그런데 부딪히지 않는다** —

    텍스트 있는 쪽   → 텍스트로 사양표·태그·날짜 판정
    스캔 쪽(71.9%)  → 판정하지 않고 PageClass.OTHER + render_path 만 채워 넘긴다

`triage/__init__.py` 주석: *"실제로 페이지를 고르려면 할 일 5(make_montage → VLM
이진 판정)가 [필요하다]"* — **VLM 판정은 구현하지 않았다.** 즉 그쪽은 쪽 목록과
렌더를 준비하는 데서 멈추고, 우리 화면이 사람에게 고르게 한다. **보완 관계다.**

조원과 확인할 것 — 할 일 5(VLM 자동 선택)를 **하지 않기로** 합의하는 것. 사람이
고르면 오류율이 내려가고 추론 비용도 없다.
